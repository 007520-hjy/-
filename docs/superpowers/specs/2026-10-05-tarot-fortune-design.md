# 塔罗 · 今日运势网站 — 设计文档

日期：2026-10-05
状态：已获用户批准（聊天中确认，用户回复「开始」）

## 目标

做一个测今日运势的网站：神秘占星风、塔罗五牌十字阵、AI 生成牌面图。

## 交互流程

1. 打开页面：星空背景 + 标题「今日运势 · 塔罗五牌阵」+ 顶部今日日期 + 中央牌堆（牌背朝上）
2. 点击「开始抽牌」→ 洗牌动画 → 五张牌依次翻到十字阵位，逐张展示解读
3. 底部「今日运势总览」：根据五张牌正逆位与关键词本地生成一句话总结
4. 「再测一次」重新抽（每次随机，不锁定每日一签）

## 五牌十字阵

```
          [上] 障碍
[左] 目标   [中] 现状   [右] 建议
          [下] 潜在
```

- 每张牌：AI 牌面图（逆位旋转 180°）+ 牌名 + 正/逆位标签 + 今日解读（1-2 句）
- 移动端：十字阵转为竖向排列（现状→障碍→潜在→目标→建议），各带位置标签

## 数据

- 22 张大阿尔克纳（愚者 0 → 世界 21），JS 数组 CARDS
- 每张：`{ id, nameZh, nameEn, keywords, upright, reversed }`
- upright/reversed 为面向「今日运势」语境的简短解读
- 抽牌：Fisher-Yates 洗牌，取前 5 张（不重复），每张独立 50% 正/逆位
- 总览：按正位数量（≥4 大吉 / ≥3 吉 / 2 平 / ≤1 谨慎）＋包含的关键词模板拼接

## 视觉

- 风格：神秘占星 —— 深蓝星空、金色纹饰、占星符号、艺术新潮（Art Nouveau）
- 23 张 AI 图（SiliconFlow）：22 张牌面 + 1 张牌背；竖版 2:3；画面不含文字（牌名由 HTML 叠加，避免 AI 文字乱码）
- 存 `images/card-XX.png`（XX=00-21）+ `images/card-back.png`，HTML 相对路径引用，双击本地可开
- 动画：纯 CSS/JS —— 洗牌、3D 翻牌、星空粒子（CSS 随机星点）
- 字体：衬线标题 + 系统无衬线正文
